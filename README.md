EN:



A Forge mod that fixes a bug in older versions.



The bug:

If you bind "toggle perspective" to one of the side mouse buttons (mouse4 or mouse5), pressing the other side mouse button while holding shift causes the first one to activate. For example, if you bind "toggle perspective" to mouse5 and an inventory slot to mouse4, switching to that inventory slot while holding shift becomes impossible.



On 1.8.9, also install the "Toggle Perspective Fixed" mod (by ArchUsr64) for proper functionality.

https://github.com/ArchUsr64/toggle\_perspective\_fixed

https://modrinth.com/mod/toggle-perspective-fix



The mod was entirely written by DeepSeek V4.1 Flash.





RU:



Мод на Forge который исправляет баг старых версий.



Суть бага:

Если забиндить "toggle perspective" на одну из боковых кнопок мыши (mouse4 или mouse5), то при зажатом shift нажатие второй боковой кнопки мыши приводит к активации первой. Например, если забиндить на mouse5 "toggle perspective", а на mouse4 слот инвентаря, то при зажатом shift переключение на слот инвентаря будет невозможно.



На 1.8.9 для корректной работы так же установите мод "Toggle Perspective Fixed" (by ArchUsr64)

https://github.com/ArchUsr64/toggle\_perspective\_fixed

https://modrinth.com/mod/toggle-perspective-fix



Мод полностью написан deepseek v4.1 flash.
